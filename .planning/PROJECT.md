# Project: The Grand Pavilion & Scholars Residency ERP
### Commercial White-Label Hostel ERP & Bespoke Architectural Showcase

## Overview
A bespoke, commercial-grade White-Label Hostel ERP and interactive 3D showcase engineered strictly under the **Zero-AI-Vibe & Humanized Craft Manifesto**. Indistinguishable from an elite custom-built European product, featuring multi-branch switching, real-time bed inventory, automated partial fee rollover, 3-voucher bank challans, direct WhatsApp slip dispatch, staff payroll, partner equity ledgers, and PWA offline capability.

## Core Directives & Guardrails
- **Zero Emojis in UI:** Emojis are strictly forbidden. All iconography uses precision 1.25px stroke monochrome SVG vector icons (`lucide-react`).
- **Mathematical Layout Rhythm:** Strict 8px/4px spacing tokens (`p-3`, `p-4`, `p-6`, `p-8`, `gap-4`, `gap-6`).
- **Bespoke Editorial Typography:**
  - Headers: `Playfair Display` serif.
  - Body: `Inter` geometric sans.
  - Urdu: `Noto Sans Arabic` Nastaleeq.
  - Constrained strictly to 4 operational font sizes (`caption`, `body`, `subhead`, `title`).
- **Palette & Materiality:**
  - Canvas: `#FAF9F6` (Warm architectural ivory/stone).
  - Ink: `#18181B` (Deep charcoal slate).
  - Rules: `#E4E4E7` (Neutral zinc 1px).
  - Primary Accent: `#B58544` (Antique Brass).

## Technology Stack
- **Framework:** Next.js 15.1.7 (App Router, Server-Side Rendering)
- **Language:** TypeScript 5.7
- **Styling:** Tailwind CSS 3.4
- **ORM & Data Layer:** Prisma 5.22 with SQLite / PostgreSQL compatibility
- **Icons:** Lucide React 1.70 (monochrome, 1.25px stroke)
- **Offline / PWA:** Standalone Manifest, Service Worker caching
- **Security:** Sliding-window rate limiter, Cloudflare Turnstile bot shield, MIME & magic-byte upload validation (< 200 KB)
