# 🏨 Haven — White-Label Commercial Hostel ERP & Showcase

> A production-grade, multi-branch Hostel Enterprise Resource Planning (ERP) platform and interactive showcase engine built with **Next.js 14 (App Router)**, **TypeScript**, **Prisma ORM**, and **PostgreSQL**.

### 🌟 Key Highlights
- **Architecture:** Multi-Property & Multi-Branch Management from a single master account
- **Inventory:** Dynamic Floor & Room Builder with real-time visual occupancy (🟢/🟡/🔴)
- **Billing & Accounting:** Automated monthly dues, partial payments, arrears, and 3-copy PDF/WhatsApp fee challans
- **Operations:** Staff payroll, attendance, expense categorisation, and partner profit/loss ledger
- **Security:** Cloudflare Turnstile bot protection, 2FA OTP, rate-limiting, and strict client/server file validation
- **Experience:** Bespoke Swiss architectural typography, zero emojis, PWA installable, and English/Urdu bilingual support
